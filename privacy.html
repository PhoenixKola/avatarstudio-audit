Privacy Policy

Effective date: June 2026

Overview

AvatarStudio is a local/internal video creation tool. It helps users create short-form videos and optionally upload completed videos to their own YouTube channel after explicit Google OAuth authorization.

Information We Process

AvatarStudio may process video project data such as scripts, generated captions, generated images, audio files, final rendered videos, YouTube upload metadata, and connected YouTube channel metadata.

YouTube Data API Usage

AvatarStudio uses the YouTube Data API only to perform actions requested by the authenticated user, such as uploading a selected video, setting title, description, tags, privacy status, made-for-kids status, altered/synthetic media disclosure, and optionally uploading caption tracks.

OAuth Tokens

OAuth refresh tokens are stored server-side and encrypted. Tokens are not exposed to the frontend. Users can disconnect their YouTube channel from AvatarStudio, which removes the stored connection.

Data Sharing

AvatarStudio does not sell user data. YouTube data is used only to provide the user-requested upload functionality.

Data Retention

Local project data and connected channel information are retained until the user deletes the project, disconnects the channel, or removes the local data.

User Control

Users can disconnect their YouTube channel at any time from the Channels page.
