AvatarStudio

Local AI video creation and YouTube upload assistant.

About

AvatarStudio is a local/internal video production tool that helps create short-form videos using AI-generated scripts, narration, captions, and generated visual scenes.

The YouTube integration allows the authenticated channel owner to upload finished videos directly to their own YouTube channel instead of downloading the MP4 and uploading it manually through YouTube Studio.

YouTube API Usage

AvatarStudio uses the YouTube Data API only after the user connects their YouTube channel through Google OAuth. The app can upload videos selected by the user, set metadata such as title, description, tags, privacy status, made-for-kids setting, altered/synthetic media disclosure, and optionally upload caption tracks.

Data and Security

OAuth tokens are stored securely server-side and are not exposed to the frontend. Users can disconnect their YouTube channel from the Channels page.
